## Фоны и видимые подписи

- Архив: закрытые бумаги / раскрытое дело; штольня: закрытый / открытый схрон.
- Сухой ряд: общий огонь / ночной свет; контора: дело на столе / сшитая папка.
- Приёмная: холодный рабочий свет / красный режим тишины.
- Машинный зал: остановка / работа, гул включается отдельно по событию ремонта.
- Каморка: закрытый / вскрытый шкаф; шахта: провал / страховка и фонарь.
- Затвор: вода у двери / вода сброшена / подготовленный клапан.
- Забой: шов / цепной бандаж / вырезанная сердцевина; после сердцевины бандаж не имеет конкурирующего условия.
- Галерея: вода у мостков / большая вода; шлюз: дневной / ночной свет.

На контактных таблицах нет новых перекрывающих сцену заголовков или однотонных плашек. Световые акценты и геометрия помещений сохраняются при смене вида. Первый вид безусловный, остальные включаются отдельно. Все названия состояний сделаны игровыми, без «Основного состояния».
