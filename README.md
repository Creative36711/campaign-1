# campaign-1 — «Каркас: Дело о седьмой помпе»

Обновление существующей кампании Chronicle Forge, 8 октября 2026. ID сохранён:
`b7305faa-8e10-4d26-96bb-f1b5ed5e493f`. Мир, герои, существующие ID и шесть концовок не заменены новым проектом.

Каркас —город-ствол из девяти ярусов, который держится на семи помпах.
Седьмая молчит, мастер ушёл в шахту. У дознавателя 72 часа на расследование
и решение о судьбе помпы. Детектив, разговоры, ремесло и выживание.

## Импорт

В репозитории оставлен только один архив — **`campaign-1.chronicle`**: ZIP Campaign Package с тремя
корневыми документами, всеми модулями и локальными медиа. Импортировать в
Chronicle Forge как кампанию; она не требует сети для загрузки ресурсов.
`__chronicle_ai__`, инструменты, тесты и план внутри архива отсутствуют.

## Что изменено

- Использованы 10 изображений: согласованные с портретами фигурки восьми
  персонажей и два изображения погибшего стражника. Тело читается в галерее
  и у затвора; Жук не парит над верстаком.
- Использованы 10 озвучек: отдельный обработанный роботический голос
  Регистратора, отличный от рассказчика; обе формы диалога синхронизированы.
- Все 26 названий состояний сцен понятны игроку. Исправлены пересечения
  условий, дыхательная анимация неживых фигурок и местоположение тела.
- 68 звуков:58 коротких +10 фонов; все фоны и 10 музыкальных треков с loop.
  Огонь во вступлениях —короткий реальный фрагмент, а не бесконечная петля.
- Закрыты повторы наград наряда, жетона и бандажа; пустая надетая маска
  больше не даёт бесконечную защиту; вой пса не заражает мировым удушьем.
- Сохранены веса встреч, но убраны случайные пары врагов. Исправлены
  обещания черт и койки, арифметика времени и запись Ярова в наряде.
- Новый контент: верёвочный путь к жетону, вынос тела с Ирой, сверка наряда,
  регистрация сшитого дела у автомата за 1 час, журнал и новый кодекс.

## Воспроизвести после пересоздания песочницы

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
npm ci
.venv/bin/python tools/validate.py
.venv/bin/python tools/schema_check.py
.venv/bin/python -m unittest discover -s tests -v
npm run check:ink
npm run test:ink
.venv/bin/python tools/audit_audio.py
.venv/bin/python tools/audit_balance.py
.venv/bin/python tools/time_budget.py
.venv/bin/python tools/check_reachability.py
.venv/bin/python tools/pack.py
```

Не запускать исторические `balance*`, `content*`, `patch*` как аудит:
многие изменяют данные и используют старые правила. Данные Git уже обновлены;
patch-скрипты текущей итерации —журнал воспроизводимости, не часть запуска.
Сборщик сначала валидирует проект, проверяет ZIP CRC и побайтовое совпадение
с источниками, затем атомарно заменяет прежний архив. Одинаковые входы дают
одинаковый архив независимо от дат файлов. Архивы задания удалены из рабочей копии: для импорта используйте только
`campaign-1.chronicle`. При необходимости исходное задание можно получить
из истории Git или main, но не хранить здесь вторым файлом `.chronicle`.
