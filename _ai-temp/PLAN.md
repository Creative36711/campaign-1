## 1. Ключевые правила (не терять!)
1. **Визуальное правило: перед генерацией любого состояния сначала СМОТРИТЬ основное изображение** (reference). Состояние = ТО ЖЕ помещение/лицо, меняется только свет, эмоция или один предмет. Никогда не рисовать «другой зал» или «другого человека».
2. Генерация состояний: `generate_image(images=[путь_к_основному_изображению])` — всегда с референсом, в промпте прописать «the room/person must stay exactly the same as the reference — only … changes».
3. После генерации — обязательно просмотреть результат и сравнить с референсом (read_file).
4. Новый регламент движка (гайд 08.10.2026): `states[0]` ВСЕГДА базовое состояние с `condition: null`, называть «Основное состояние» (не «Всегда»/«Днём»); за ним — условные состояния. Движок отдаёт приоритет условным, иначе базовое.
5. `SceneCondition` (сцены/слоты) принимает ТОЛЬКО: `time_of_day` (enum или массив), `flag`, `not_flag`, `weather`. Нет `not/or/and`. Сложное «не (A или B)» — только через составной флаг.
6. Триггеры правил: пролог/вступительные — `always` (или пусто). `time_tick` — только для дедлайнов/событий хода.
7. Музыку и звуки — только реальные сэмплы (CC0), синтез не использовать. Новые звуки искать в существующих реестрах `campaign.sounds`.
8. Не переименовывать и не переиспользовать id сущностей.
9. После правки: `python3 _ai-temp/validate.py` → 0 ошибок; коммит + пуш в конце хода.
10. Озвучка: норма громкости реплик ~ -19 дБ RMS (peak ~ -2 дБ). Файл тише медианы голоса на >8 дБ или абсолютный RMS < -35 → переозвучить (см. analyze_audio.py).

## 8. Вопросы, уже отвечанные мастеру
- Печка в Конторе дознавателя: не баг (sfx интро), но доведено до ума (ambient).
- Прослушивать аудио «ушами» нельзя; замеряю объективно (RMS/peak/тишина) — см. _ai-temp/analyze_audio.py.
- Переозвучка тем же голосом: точная идентификация старого голоса невозможна (voice_id сессий прошлых ИИ не переносится, «уша» нет). Слушатель выбирает нового из пары кандидатов; близость определяется им по прослушиванию.
